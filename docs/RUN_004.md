# Run 004 — Computational-Behavior / Delta KD

**Status: initial run complete; matched replication required for the causal RQ1 comparison.**

Run 004 targets the project's central **Beyond Layer Matching** hypothesis. Run 003 used conventional pointwise intermediate matching:

`h_student[l+1] ≈ h_teacher[m(l)+1]`

Run 004 instead matches the **residual contribution** made by each student layer to the teacher's complete span assigned to that layer:

`h_student[l+1] - h_student[l] ≈ h_teacher[b] - h_teacher[a]`

where `[a,b)` is the teacher-layer span assigned to student layer `l`.

## What Run 004 tests

The experiment asks whether matching **what computation changes in the residual stream** produces stronger teacher-behavior alignment than matching fixed intermediate layer positions.

A positive result is not "the delta loss fell." The primary scientific comparison is whether, at a matched training budget, behavioral KD improves output-level teacher imitation and held-out behavior relative to pointwise layer KD, including:

- teacher KL / KD divergence;
- student/teacher top-1 agreement;
- validation loss;
- and, only in later capability runs, downstream benchmark quality.

## Objective definition

Run 004-M uses the existing validated `layer_kd` trainer path under the hood, with the launcher forcing `mode="delta"`. The authoritative sidecar manifest identifies the actual objective as `behavioral_kd`.

The student target is `h_s[l+1] - h_s[l]`.

The teacher target is `h_t[b] - h_t[a]` over the complete assigned span `[a,b)`.

All teacher layers are covered exactly once by the span construction. This means the 16 teacher layers not represented by one-to-one student layer identities are absorbed into neighboring student spans rather than silently dropped.

Run 004 does **not** match DeltaNet recurrent-state tensors and does not introduce a learned recurrent-state projection.

## Staged evidence after Run 004-M

A matched 128-step replication is the causal control. If its output-level result is positive or non-inferior, scale the same behavioral objective in stages:

- 1,024 steps / 1,572,864 training tokens;
- 4,096 steps / 6,291,456 training tokens;
- 16,384 steps / 25,165,824 training tokens only if the previous stage remains healthy and compute budget permits.

These stages do not change the per-step memory shape; the 45 GiB guard remains mandatory.

The longer stages answer whether a short-run behavioral advantage persists beyond the 128-step mechanistic regime.

## Composite-objective follow-up

Pure behavioral KD is deliberately not assumed to be the final training objective. If the matched behavioral arm is promising, compare it against a composite teacher-guided objective that includes ground-truth CE and logit KD. This is important because a teacher can be wrong; the final training design should test whether ground-truth supervision corrects or improves teacher-only behavior transfer.

## Evidence interpretation

### Evidence for the hypothesis

The strongest RQ1 evidence is a controlled and persistent improvement in output-level teacher alignment and/or held-out behavior for Run 004-M over Run 003, followed by a similar advantage in the longer-budget behavioral run.

### Evidence against the hypothesis

The hypothesis is weakened if the matched behavioral arm repeatedly fails to improve output-level alignment or validation behavior, or if any short-run advantage disappears under longer training.

### Inconclusive outcome

If delta loss improves but output-level alignment and validation do not, the result establishes trainability of the behavioral target but not a useful advantage.

## Relation to the broader paper

Run 004-M is evidence for RQ1. It does not answer the context-specialization question. RQ2 requires separate controlled context-distribution experiments with equalized total training tokens and a common evaluation suite.
